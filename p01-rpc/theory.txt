3. ✅ Viva Questions with Short Answers

Q1. What is RPC?
RPC is Remote Procedure Call used for communication between distributed systems.

Q2. Why RPC is used?
To call functions on remote machines like local functions.

Q3. What is client-server architecture?
Client sends requests and server processes them.

Q4. What is XML-RPC?
Protocol using XML for data exchange in RPC.

Q5. Why port 8000 is used?
To establish communication channel between client and server.

Q6. Why server runs first?
Because client requires active server connection.

Q7. What is ServerProxy?
Client-side object used to access remote methods.

Q8. Why use localhost?
To run client and server on same machine.

Q9. What happens if server is not running?
Client gives connection refused error.

Q10. Difference between RPC and RMI?
RPC uses procedures/functions while RMI uses objects/methods.

4. ✅ Practical Explanation in Detail

🔹 Introduction
This practical demonstrates communication between two distributed processes using RPC (Remote Procedure Call).
The client sends an integer to the server and the server calculates factorial and returns the result.

🔹 Working Principle
RPC works using client-server architecture.


Client requests service


Server processes request


Server returns result


The client does not directly execute factorial logic.
Instead:


It sends request through network


Server executes function remotely



🔹 Server Responsibilities
The server:


Creates RPC server


Registers factorial method


Waits for client requests


Calculates factorial


Sends result back



🔹 Client Responsibilities
The client:


Connects to server


Takes user input


Calls remote method


Displays factorial result



🔹 Factorial Logic
Factorial of number:
n!=n×(n−1)×(n−2)×⋯×1

Example:
5!=5×4×3×2×1=120
5! = 5 \times 4 \times 3 \times 2 \times 1 = 120
5!=5×4×3×2×1=120

🔹 Advantages of RPC


Distributed communication


Easy remote execution


Simplifies network programming


Supports client-server model



🔹 Applications


Distributed systems


Banking systems


Cloud computing


Remote services
