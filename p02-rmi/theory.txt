✅ PRACTICAL 2 — RMI String Concatenation using Pyro4

📄 Topic:
Distributed application using RMI where client sends two strings and server returns concatenated string.

====================================================================================================

1. ✅ How to Run in Short

🔹 Step 1 — Install Pyro4
pip install Pyro4

Reason:
Pyro4 library is required for Remote Method Invocation in Python.

--------------------------------------------------

🔹 Step 2 — Start Pyro Name Server
pyro4-ns

Reason:
Name server helps clients locate remote server objects.

--------------------------------------------------

🔹 Step 3 — Open another terminal and run server
python server.py

Reason:
Server creates remote object and registers it with Pyro Name Server.

--------------------------------------------------

🔹 Step 4 — Copy generated URI

Reason:
Client needs URI to connect to remote server.

--------------------------------------------------

🔹 Step 5 — Open another terminal and run client
python client.py

Reason:
Client sends remote request to server.

--------------------------------------------------

🔹 Step 6 — Paste URI and enter strings

Example:
Hello
World

Reason:
Strings are sent remotely to server for concatenation.

--------------------------------------------------

🔹 Step 7 — Stop processes
CTRL + C

Reason:
Stops server and frees resources.

3. ✅ Viva Questions with Short Answers

Q1. What is RMI?
RMI is Remote Method Invocation used to call methods on remote objects.

--------------------------------------------------

Q2. What is Pyro4?
Pyro4 is a Python library for distributed object communication.

--------------------------------------------------

Q3. Why Pyro4 is used?
To simplify remote communication between Python programs.

--------------------------------------------------

Q4. What is Name Server?
It stores and locates remote object references.

--------------------------------------------------

Q5. What is URI in Pyro?
URI uniquely identifies remote object location.

--------------------------------------------------

Q6. Why server runs first?
Because client requires active remote object connection.

--------------------------------------------------

Q7. What is daemon in Pyro?
Daemon handles remote requests from clients.

--------------------------------------------------

Q8. Difference between RPC and RMI?
RPC calls functions while RMI calls object methods.

--------------------------------------------------

Q9. Why use localhost?
To run distributed application on same machine.

--------------------------------------------------

Q10. What happens if Name Server is not running?
Server and client cannot locate remote objects.

4. ✅ Practical Explanation in Detail

🔹 Introduction

This practical demonstrates distributed communication using Remote Method Invocation (RMI) in Python with Pyro4.

The client sends two strings to the server.
The server concatenates both strings and sends result back to client.

--------------------------------------------------

🔹 Working Principle

RMI follows client-server architecture.

1. Server creates remote object.
2. Server registers object with Name Server.
3. Client connects using URI.
4. Client invokes remote method.
5. Server processes request.
6. Result is returned to client.

--------------------------------------------------

🔹 Role of Name Server

The Name Server acts like a directory service.

It:
- Stores remote object URIs
- Helps clients find servers
- Simplifies distributed communication

--------------------------------------------------

🔹 Server Responsibilities

The server:
- Creates remote object
- Registers object
- Waits for requests
- Processes string concatenation
- Returns result

--------------------------------------------------

🔹 Client Responsibilities

The client:
- Connects to remote server
- Sends strings
- Invokes remote method
- Displays result

--------------------------------------------------

🔹 String Concatenation Logic

Concatenation combines two strings.

Example:
"Hello" + "World" = "HelloWorld"

--------------------------------------------------

🔹 Advantages of RMI

- Supports distributed computing
- Simplifies remote communication
- Object-oriented communication
- Easy method invocation

--------------------------------------------------

🔹 Applications

- Distributed systems
- Cloud computing
- Remote services
- Enterprise applications
