4. ✅ Practical Explanation in Detail

🔹 Introduction

This practical demonstrates implementation of MapReduce for weather data analysis.

The objective is to:
- Calculate average yearly temperature
- Find hottest year
- Find coolest year

--------------------------------------------------

🔹 MapReduce Concept

MapReduce is a programming model used in distributed systems for processing large datasets.

It works in two major phases:
1. Map Phase
2. Reduce Phase

--------------------------------------------------

🔹 Map Phase

The Mapper:
- Reads input data
- Converts data into key-value pairs

Example:

Input:
2010,30

Output:
(2010, 30)

--------------------------------------------------

🔹 Reduce Phase

Reducer:
- Groups values by key
- Performs aggregation

Example:

(2010, [30,32])

Average:
31

--------------------------------------------------

🔹 Weather Dataset

Dataset contains:
- Year
- Temperature

Example:

2010,30
2010,32

--------------------------------------------------

🔹 Average Temperature Calculation

Formula:

Average = Sum of temperatures / Number of records

--------------------------------------------------

🔹 Hottest and Coolest Year

After calculating averages:
- Maximum average → Hottest year
- Minimum average → Coolest year

--------------------------------------------------

🔹 Advantages of MapReduce

- Handles large data
- Supports distributed computing
- Parallel processing
- Fault tolerance

--------------------------------------------------

🔹 Hadoop Framework

Hadoop uses MapReduce internally.

Components:
- HDFS
- MapReduce Engine
- YARN

--------------------------------------------------

🔹 Applications

- Weather forecasting
- Search engines
- Social media analysis
- Data mining
- Log processing
