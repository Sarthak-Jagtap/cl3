4. ✅ Practical Explanation in Detail

🔹 Introduction

This practical demonstrates implementation of load balancing algorithms used in distributed systems.

Load balancing helps distribute incoming client requests across multiple servers efficiently.

--------------------------------------------------

🔹 Need for Load Balancing

If all requests go to one server:
- Server becomes overloaded
- Performance decreases
- System may crash

Load balancing solves this problem by distributing workload evenly.

--------------------------------------------------

🔹 Load Balancer

A load balancer acts as an intermediary between:
- Clients
- Multiple servers

It decides which server should handle each request.

--------------------------------------------------

🔹 Round Robin Algorithm

Round Robin distributes requests one-by-one in circular order.

Example:

Request 1 → Server A
Request 2 → Server B
Request 3 → Server C
Request 4 → Server A

Advantages:
- Simple
- Fair distribution

--------------------------------------------------

🔹 Random Load Balancing

Random algorithm selects server randomly.

Advantages:
- Easy implementation
- Randomized distribution

Disadvantages:
- Uneven load possible

--------------------------------------------------

🔹 Hashing Algorithm

Hashing uses request ID to determine server.

Formula:

Server = RequestID % NumberOfServers

Advantages:
- Consistent mapping
- Useful for caching

--------------------------------------------------

🔹 Simulation of Requests

The program simulates multiple requests and applies all algorithms to show server allocation.

--------------------------------------------------

🔹 Advantages of Load Balancing

- Better performance
- High availability
- Fault tolerance
- Efficient resource utilization

--------------------------------------------------

🔹 Applications

- Cloud computing
- Web servers
- Banking systems
- E-commerce websites
