4. ✅ Practical Explanation in Detail

🔹 Introduction

This practical demonstrates implementation of Ant Colony Optimization (ACO), a swarm intelligence algorithm inspired by real ant behavior.

ACO is mainly used for:
- Shortest path problems
- Optimization problems
- Traveling Salesman Problem (TSP)

--------------------------------------------------

🔹 Biological Inspiration

Real ants search for food randomly.

While moving:
- They deposit pheromones on paths.
- Other ants follow stronger pheromone trails.
- Shorter paths accumulate more pheromones.

Finally:
- Entire colony converges toward shortest path.

--------------------------------------------------

🔹 Swarm Intelligence

ACO belongs to Swarm Intelligence techniques where multiple agents cooperate to solve problems.

Agents:
- Ants

Communication:
- Pheromones

--------------------------------------------------

🔹 Objective of Practical

The objective is to find shortest path among cities using artificial ants.

--------------------------------------------------

🔹 City Representation

Cities are represented using coordinates:

Example:
[0,0], [1,2], [3,1]

--------------------------------------------------

🔹 Pheromone Matrix

Pheromone matrix stores pheromone intensity between cities.

Initially:
All paths have equal pheromone.

--------------------------------------------------

🔹 Distance Calculation

Distance between cities is calculated using Euclidean distance formula.

Formula:

d = √[(x₂-x₁)² + (y₂-y₁)²]

--------------------------------------------------

🔹 Probability Formula

Ant chooses next city using probability:

P = (pheromone^alpha) × ((1/distance)^beta)

Where:
- alpha → pheromone importance
- beta → distance importance

--------------------------------------------------

🔹 Pheromone Evaporation

Old pheromone trails gradually decrease.

Purpose:
- Avoid unlimited pheromone accumulation
- Encourage exploration

--------------------------------------------------

🔹 Pheromone Deposition

Ants deposit pheromones on traveled paths.

Shorter paths receive:
- More pheromone
- Higher probability

--------------------------------------------------

🔹 Best Tour

Algorithm continuously updates:
- Best path
- Minimum distance

--------------------------------------------------

🔹 Advantages of ACO

- Good optimization ability
- Distributed computation
- Adaptive behavior
- Finds near-optimal solutions

--------------------------------------------------

🔹 Applications

- Network routing
- Vehicle routing
- Robotics
- Scheduling
- Traveling Salesman Problem
