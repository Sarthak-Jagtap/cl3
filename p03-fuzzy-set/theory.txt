4. ✅ Practical Explanation in Detail

🔹 Introduction

This practical demonstrates operations on fuzzy sets and fuzzy relations.

Unlike classical sets, fuzzy sets allow partial membership values between 0 and 1.

--------------------------------------------------

🔹 Fuzzy Set Concept

A fuzzy set is represented using membership values.

Example:

A = {x1:0.2, x2:0.7, x3:1.0}

Here:
- x1 belongs to set with degree 0.2
- x2 belongs with degree 0.7
- x3 fully belongs with degree 1.0

--------------------------------------------------

🔹 Union Operation

Union combines two fuzzy sets using maximum membership values.

Formula:

μ(A ∪ B) = max(μA(x), μB(x))

--------------------------------------------------

🔹 Intersection Operation

Intersection uses minimum membership values.

Formula:

μ(A ∩ B) = min(μA(x), μB(x))

--------------------------------------------------

🔹 Complement Operation

Complement represents opposite membership.

Formula:

μ(A') = 1 - μA(x)

--------------------------------------------------

🔹 Difference Operation

Difference operation subtracts one fuzzy set from another.

Formula:

A - B = min(A, 1-B)

--------------------------------------------------

🔹 Fuzzy Relations

Fuzzy relation is created using Cartesian Product.

It combines elements from two fuzzy sets.

--------------------------------------------------

🔹 Cartesian Product

Cartesian Product creates ordered pairs.

Formula:

R(x,y) = min(A(x), B(y))

--------------------------------------------------

🔹 Max-Min Composition

Max-Min Composition combines fuzzy relations.

Steps:
1. Take minimum values row-wise.
2. Take maximum values column-wise.

--------------------------------------------------

🔹 Advantages of Fuzzy Logic

- Handles uncertainty
- Supports approximate reasoning
- Useful in intelligent systems
- Human-like decision making

--------------------------------------------------
