4. ✅ Difference Between Java RMI and Python RMI (Pyro4)

Java RMI                                  Python RMI (Pyro4)

Only Java language                     Python-based implementation

Built-in Java API                      External library (Pyro4)

Uses Remote Interface                  Uses exposed classes

Uses RMI Registry                      Uses Pyro Name Server

Strict object-oriented                 More flexible and lightweight

Requires compilation                   Interpreted execution

More secure and robust                 Easier implementation

Used mainly in enterprise systems      Used in lightweight distributed systems

5. ✅ Practical Explanation in Detail

🔹 Introduction

This practical demonstrates implementation of a distributed Hotel Booking System using Java RMI.

RMI allows methods of remote objects to be invoked from another JVM.

The system allows clients to:
- Book hotel rooms
- Cancel bookings

through remote communication.

--------------------------------------------------

🔹 Java RMI Architecture

Java RMI uses:
1. Client
2. Server
3. Remote Interface
4. RMI Registry

--------------------------------------------------

🔹 Remote Interface

The remote interface defines methods accessible remotely.

Methods:
- bookRoom()
- cancelBooking()

--------------------------------------------------

🔹 Server

The server:
- Implements remote interface
- Stores booking information
- Registers object with RMI registry
- Waits for client requests

--------------------------------------------------

🔹 Client

The client:
- Connects to RMI registry
- Looks up remote object
- Invokes booking methods remotely

--------------------------------------------------

🔹 RMI Registry

Acts like a directory service.

It stores:
- Remote object names
- Object references

--------------------------------------------------

🔹 Hotel Booking Logic

Booking:
- Checks room availability
- Stores booking details

Cancellation:
- Searches customer booking
- Removes booking from records

--------------------------------------------------

🔹 Synchronization

Synchronized methods ensure:
- Multiple clients do not modify data simultaneously
- Data consistency is maintained

--------------------------------------------------

🔹 Advantages of Java RMI

- Object-oriented communication
- Distributed computing support
- Easy remote invocation
- Secure communication

--------------------------------------------------

🔹 Applications

- Banking systems
- Hotel reservation systems
- Distributed enterprise systems
- Online ticket booking

6. ✅ Algorithm (Detailed)

🔹 Step 1:
Start the RMI server.

--------------------------------------------------

🔹 Step 2:
Create remote object implementing booking methods.

--------------------------------------------------

🔹 Step 3:
Create RMI registry on port 1099.

--------------------------------------------------

🔹 Step 4:
Register remote object with registry using Naming.rebind().

--------------------------------------------------

🔹 Step 5:
Start client application.

--------------------------------------------------

🔹 Step 6:
Client searches remote object using Naming.lookup().

--------------------------------------------------

🔹 Step 7:
Display menu options:
1. Book Room
2. Cancel Booking
3. Exit

--------------------------------------------------

🔹 Step 8:
If booking selected:
- Read customer name
- Read room number
- Call remote bookRoom() method

--------------------------------------------------

🔹 Step 9:
Server checks room availability.

--------------------------------------------------

🔹 Step 10:
If room available:
- Store booking
- Return success message

Else:
- Return booking failed message

--------------------------------------------------

🔹 Step 11:
If cancellation selected:
- Read customer name
- Call remote cancelBooking() method

--------------------------------------------------

🔹 Step 12:
Server removes booking if found.

--------------------------------------------------

🔹 Step 13:
Display result to client.

--------------------------------------------------

🔹 Step 14:
Repeat until user exits.
